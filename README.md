# チャージ・ラン (Web 版)

押すだけで跳ぶ 1 キーの避けゲー。空中の「充電帯」に居る間だけ点が入り、ゲージが溜まる。
ゲージ満タンで無敵 (RUSH) になり、障害物を壊して稼げる。**1000 点に届くまでのタイムを競う**。
届いても届かなくても、その回の記録を X にポストできる。

- 公開 URL: https://cosara22.github.io/chargerun/
- 元は M5Stack Cardputer ADV 向けに作ったゲーム (`Projects/dev/cardputer-chargerun`)。
  座標・物理係数・しきい値は実機と同じ値。

## 操作

| 入力 | 動作 |
|---|---|
| 任意のキー / 画面タップ (短押し) | 小ジャンプ (帯の下層) |
| 同上 (120ms 以上の長押し) | 大ジャンプ (帯の上層) |
| ミス後 350ms・クリア後 1.2 秒経ってから押す | 再開 |

## 実機版との違い

| 項目 | 実機版 | Web 版 |
|---|---|---|
| 終わり方 | ミスするまで続く | 目標点 `CLEAR_SCORE` (1000) に届いたら終わり、そのタイムが記録になる |
| HUD | SCORE / BEST | `SCORE 523/1000`・経過タイムと自己ベストのタイム・目標までの進捗バー。タイトル画面に自己ベスト (タイム・点数) |
| 到達時 | — | 到達タイム・RUSH 回数を表示し、X の投稿画面 (Web Intent) へのリンクを出す (本文は「1000点到達 31.2秒！」+「あなたは何秒で届く？」) |
| ミス時 | 赤い `CRASH`・130Hz 300ms の低いブザー | 失敗でなく「記録」として見せる。見出しは `NEW BEST!` / `SO CLOSE!`(目標の 75% 以上)/ `NICE RUN`、赤は使わない。走った秒数と目標までの進捗バー(自己ベストに印)。音は短い衝突音+上がり調のチャイム。**ミスでも X にポストできる**(本文は記録+「ゴールは1000点。あなたは届く？」) |
| 記録 | NVS | localStorage (`chargerun.best` / `chargerun.bestClearMs`) |

X へのポストは `https://x.com/intent/post?text=…&url=…` を新しいタブで開くだけで、
API キーは使わない。投稿ボタンを押すのはプレイヤー本人。
ハッシュタグは本文の最終行に `#チャージラン #生成AIなんでも展示会`(`src/main.js` の `HASHTAGS`)。

## 目標点 1000 とタイムアタックにした経緯

最初は 2000 点で「クリア」にしていたが、2026-09-23 のユーザー指示で
**1000 点に届くまでのタイムを競う**形に変えた(届かなかった回は点数を記録として出す)。

`node tools/calibrate.mjs [走数] [深さ]` の実測 (2026-09-23・20 走):

| 測定 | 結果 |
|---|---|
| 当たりを無視して大ジャンプを繰り返す (上限の目安) | 60.7 点/秒 |
| 先読み bot (未来の出現を知り反応 0) | 全走 300 秒生存。1000 点到達は中央 16.2 秒・最短 14.9 秒 |

bot は人より強いので 16.2 秒は下限として読む。最高速 (約 24 秒で到達) より前に届けば速いタイム、
粘って最高速の中で届くと遅いタイムになり、腕の差がタイムに出る。**人の試遊では未確認**。
目標点を変えるときは `src/core.js` の `CLEAR_SCORE` と、`index.html` の説明文・OGP 文言、
`tools/make_og.py` の文言を揃える。

## 構成

ビルド工程なしの静的サイト (ES モジュール)。GitHub Pages で `main` ブランチのルートを配信する。

| ファイル | 役割 |
|---|---|
| `index.html` | ページ・OGP / X カード・クリアパネル |
| `src/core.js` | ロジック (DOM 非依存。Node から読める) |
| `src/render.js` | 描画 (240x135 実寸) |
| `src/audio.js` | 矩形波の効果音 |
| `src/main.js` | 入力・ループ・記録・X ポストのリンク生成 |
| `og.png` | X / OGP カード画像 (1200x675)。`python tools/make_og.py` で作り直せる |

## 確認

```powershell
python tools/e2e.py      # Playwright で E2E (25 項目)。スクショは tools/out/
node tools/calibrate.mjs # 目標点の実測
```

ローカル (`localhost` / `127.0.0.1`) でだけ `?goal=N` で目標点を下げられる。
公開先で効くとクリアを偽ってポストできるため、ホスト名で閉じている。
